# Fermento

Aplicación de aprendizaje gamificado: sesiones cortas en el celular, repaso espaciado y lecturas breves.
Alpha personal sobre desnitrificación.

**App:** https://facarreno.github.io/fermento/ — se instala desde el navegador («Agregar a pantalla de inicio»).

Este repositorio contiene solo la app publicada. Todo el contenido pasa por revisión del autor antes de
publicarse; el contenido fuente y las herramientas viven aparte.
